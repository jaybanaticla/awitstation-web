# AwitStation

Marketing site for [AwitStation](https://awitstation.com), a bring-your-own karaoke player from Bana Computing.

- `/` — home
- `/terms` — Terms of Use (Version 2, draft web copy)
- `/privacy` — Privacy Policy (Version 2, draft web copy)

```bash
npm install
npm run dev
npm run build
```

The in-app terms and privacy text apply until these web copies are final.
